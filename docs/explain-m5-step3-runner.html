Q1. EVAL-0005의 상태가 UNOBSERVED인 것은 검증 실패를 의미하는가? 정답 확인
💡 아닙니다! EVAL-0005는 7개 AC 중 5개 항목이 런타임 대화 로그 미제출로 인해 "지침 존재 ≠ 동작 관측" 원칙에 따라 UNOBSERVED로 정상 판정된 공식 실측 상태입니다. 이전 기준선 대비 상태 전이가 없으므로 회귀가 발생하지 않았음을 뜻합니다.
Q2. scripts/run-evals.js를 실행하기 위해 npm install이 필요한가? 정답 확인
💡 전혀 필요하지 않습니다! V2 절대 원칙(Thin Harness / Zero-Dependency)에 따라 표준 Node.js 내장 모듈만으로 설계되어 저장소 클론 즉시 node scripts/run-evals.js 한 줄로 4.1ms 만에 실행됩니다.

  • node scripts/run-evals.js --update-baseline : 실측 결과로 기준선 스냅샷 갱신
  • node scripts/run-evals.js --json : 기계 판독용 JSON 출력
