# Dashboard 디자인 정합화본 — 이슈 5

원문은 `docs/m5-r/dashboard-design-source.md`로 보존한다(사용자 제공 `OWNHANDS_DESIGN.md`,
`version: alpha`, `name: OwnHands-dashboard-design`). 이 문서는 원문을 대체하지 않고,
승인 SDD·가독성 기준과 어긋나는 항목의 변경 이력만 기록한다.

우선순위는 원문 §21 그대로다: `OwnHands product contract / SDD > DESIGN.md`.

## 사용자 확정 지시 (구현 기준)

> 시안의 정보 계층·톤·전체 UX는 구현 기준으로 따른다. 픽셀 단위 너비·간격·줄바꿈·breakpoint는
> 실제 브라우저에서 더 자연스러운 결과를 위해 조정할 수 있다. 데이터·상태·보안 계약은 변경하지
> 않는다. 시안을 픽셀 퍼펙트하게 복제하는 것보다 실제 데이터에서 깨지지 않는 UI를 우선한다.

3~7의 원본 hue는 버리지 않았다. **아이콘 stroke와 경계선(3:1 기준)에는 원본을 그대로 쓰고,
같은 의미의 텍스트만 AA 통과 ink로 분리**한다.
