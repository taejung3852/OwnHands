# #79 파일별 책임표

기준: `598f651614df36afc3d3d303d3aaeaff596ee6b2`. 추적 파일 **206개**를 각 1행으로 분류한다. 원문은 수정하지 않는다.

`keep`은 책임 유지이며 옛 API의 영구 고정을 뜻하지 않는다. `compat`는 명시적 전환 전 호환 유지, `remove-later`는 의존성·회귀 확인 전 삭제 금지인 후보, `historical-only`는 보존하되 현행 완료 근거로 승계하지 않는 자료다. 역사 재현 실행기는 실행 가능한 상태로 남아 있을 수 있다.
