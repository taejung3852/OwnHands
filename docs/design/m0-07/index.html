주의실제 장애는 아직 모름

전원 손실·디스크 부족·동시 쓰기는 다음 단계입니다.

왜 이런 결론인가요?
작업 기록은 순서와 중복을 관리하기 쉬운 SQLite에 둡니다. 크거나 민감한 원본은 Git에 들어가지 않는 로컬 파일로 분리해, 결과와 근거를 잃지 않고 연결합니다.
무엇을 확인했나요?
중간에 멈춘 쓰기의 되돌리기, 같은 기록의 중복 방지, 원본 hash 일치, 화면용 요약 재생성, Git 제외, SQLite 무결성을 합성 환경에서 확인했습니다.
아직 모르는 것은 무엇인가요?
실제 전원 손실, 디스크가 가득 찬 상황, 동시에 여러 작업이 쓰는 상황, 대용량 파일, 보존 기간 경합, 암호화는 아직 확인하지 않았습니다.
