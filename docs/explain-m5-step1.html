Q1. V2-M5는 평가를 아예 처음부터 새롭게 만드는 마일스톤인가? 정답 확인
💡 아닙니다! 평가는 이미 M1부터 작게 시작하여 5건을 축적해 두었습니다. M5는 이를 바탕으로 '체계화(Task Set 규격화 및 자동 러너 설계)'로 도약하는 확장점입니다.
Q2. 에이전트 평가 시 이전 캐시 조회를 새로운 통과 표본으로 셀 수 있는가? 정답 확인
💡 절대 불가합니다! 동일 캐시 조회를 독립 생성 평가로 부풀려 계산하는 것은 AGENTS.md와 로드맵 규칙에서 엄격히 금지된 자기기만입니다.
🛠️ Step ① 조사 질문 및 엔지니어링 경계

이슈 #131에서 해결할 핵심 질문:

  • 5대 마크다운 Eval 사례를 어떤 머신 판독 가능(JSON/YAML) 스키마로 표준화할 것인가?
  • Codex CLI 또는 독립 스크립트를 통해 외부 부작용(이슈 무단 생성) 없이 비대화형 Dry-run을 돌리는 구조는 무엇인가?
  • 지침 변경 시 회귀를 감지하는 사전 측정치(Baseline)의 기록과 비교 판정 알고리즘은 무엇인가?

의도적으로 제외한 항목 (Non-goals):

  • 대규모 벤치마크나 여러 외부 모델 간의 비교 (범위 초과)
  • PR 머지를 무조건 차단하는 고정 게이트 규칙 (조기 결정 안티패턴 배제)
