왜 Step 4가 필요한가? (이론 ➔ 실사용)

③ 정책 계층화 및 거버넌스 경계 정리 완료 (#105) ✅
④ 그 흐름을 '실제로 사용'하고 있는가? Step 4의 목표 🎯
2
Step 4에서 실제로 하는 3가지 작업
선정한 실제 기능 1건을 대상으로 docs/specs/ 아래에 아티팩트를 만들고 구현합니다.
1
intent.md 작성 (의도 & 비목표 합의)
"왜 필요한가, 무엇을 만들고 무엇을 절대 안 할 것인가"를 사람이 명시
2
spec.md 생성 (AI 분석 기반 기술 청사진)
데이터 모델, 함수 시그니처, 엣지 케이스, 수용성 기준을 AI가 구체적으로 기술 ➔ 사람 검토
3
실제 코드 구현 및 테스트 검증 (관통 실측)
스펙대로 코드를 구현하고 테스트를 돌려, 이 프로세스가 군더더기 없이 매끄러운지 확인
3
어떤 이슈에서 하는 건가? (신규 이슈 발행)
