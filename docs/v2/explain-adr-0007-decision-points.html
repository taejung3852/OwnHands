⚡ 3초 점검 퀴즈
Q1. 기존 테스트가 아예 없는 프로젝트는 회귀 테스트를 어떻게 방어할까? 정답 확인
A: Target Files 외 무단 수정 절대 금지(Blast Radius Guard) + 전체 빌드(`build`) 및 린트(`lint`) 무에러 통과를 대체 증거로 요구합니다.
Q2. TDD만 돌리면 다른 팀원의 기존 기능이 안전할까? 정답 확인
A: 아닙니다. TDD는 현재 파일의 단위 테스트만 돌리므로, 완료 직전 회귀 테스트 스위트 실행을 통해 기존 기능의 실패 미관측(No failures observed)을 확인해야 합니다.
