엔지니어링 세부사항: 생략된 기술 전제와 미확인 Gap
  • 생략된 전제: 각 에이전트는 .codex/agents/*.toml에 정의되며, verifier와 reviewer는 sandbox_mode = "read-only"로 설정되어 있습니다.
  • 전문가의 예외 지적: Codex 공식 사양상 부모 세션의 라이브 권한(--yolo 등)이 자식 에이전트의 read-only를 무효화할 수 있으므로, 하드 보안 강제가 아닌 '소프트 경계'로 취급합니다.
  • 미확인 사양: 부모의 전체 대화 히스토리가 자식 서브에이전트에게 자동 상속되지 않으므로, 호출 시 프롬프트에 명확한 수용 기준을 직렬화해야 합니다.
