V2 Continuous Evals: 작은 Eval에서 체계로

핵심 비유: 완공 후 한 번에 검사하는 것이 아니라, 벽돌 한 장 올릴 때마다 수평계(작은 Eval)를 대어 기울어짐(퇴행)을 바로잡는 건축 방식입니다.

스스로 풀어보는 확인 퀴즈 3문항

  1. Eval은 V2-M5에 가서 처음 시작하는 것인가요? (정답: 아니오, M1부터 작은 Eval 시작)
  2. 테스트 중 실제 GitHub 이슈를 발행하지 않은 이유는? (정답: 테스트로 인한 원격 저장소 오염 방지 및 초안 한정 제약 준수)
  3. 작은 Eval의 결과는 어디에 어떻게 기록되나요? (정답: docs/v2/evals/ 아래 순번 마크다운 파일로 원응답 보존)
엔지니어링 세부사항: 생략된 기술 전제 및 미확인 Gap
  • 생략된 전제: 현재 M1 단계에서는 CI 비대화형 실행기가 없으므로 세션 내 대화형 실측을 수행함.
  • 전문가라면 짚을 예외: Codex CLI의 subagent `read-only`는 부모의 live permission override에 의해 뚫릴 수 있으므로 OS 레벨 샌드박스가 추가되어야 함.
  • 미확인 Gap: Codex Cloud 환경에서의 비대화형 CI 실행 방법은 이슈 #102 후속 조사 필요.
