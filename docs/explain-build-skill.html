아니다. 실행 가능한 로직이고 plan이 TDD를 지정한 경우에만 tdd-loop를 읽는다.

쉽게 그리느라 생략한 조건

  • AGENTS.md의 한 문장이 승인된 Build 문맥을 build Skill로 연결한다.
  • tdd-loop.md와 subagent-routing.md는 조건이 맞을 때만 읽는 Progressive Disclosure 구조다.
  • Spec 충돌이나 새 제약이 발견되면 spec 수정 → 사람 승인 → plan 재정렬로 돌아간다.

예외 및 미확인 사실

  • Skill은 Runner나 Hook이 아니라 Codex가 읽는 실행 지침이다.
  • 제공된 quick_validate.py는 환경의 PyYAML 부재로 UNOBSERVED였다. 필수 계약은 직접 정적 검사했다.
  • 현재 결과는 codex/140-thin-build-skill 브랜치의 미커밋 변경이다.
