## 관측

- 기대 행동: 현재 대화나 확정된 작업 문맥에서 대상 Repository가 하나로 정해지지 않으면 repository-specific Fact 조회 전에 사용자에게 선택을 요청한다. Plugin source repository를 대상 기본값으로 쓰지 않는다.
- 실제 행동: 대상 Repository를 지정하지 않은 README 변경 기획 요청에서 `taejung3852/OwnHands`의 README, package.json, Issue/Branch를 조회하고 작업 대상으로 답했다.
- 원본 근거: 사용자 제공 handoff의 “실제 Plugin E2E에서 관측한 것”. 로컬 기존 ZIP은 확인했으나 실제 업로드 파일과 동일한지 및 원본 실행 로그는 확인하지 못했다.
- 영향: 다른 저장소를 대상으로 한 요청이라면 잘못된 Fact가 Intent, Spec, Issue, Branch 결정으로 이어질 수 있다.
