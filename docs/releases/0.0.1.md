# OwnHands 0.0.1 — First Public Baseline

OwnHands의 현재 Codex-native 개발 흐름을 다른 Git 프로젝트에 연결할 수 있는 첫 공개 실험판이다.

## Established

- Intent → Spec → Plan → Build → Verify → Review → Human Gate → Feedback 흐름
- 7개 Skill과 3개 read-only Agent
- 기존 설정을 보존하는 `init`과 drift를 읽기 전용으로 확인하는 `doctor`
- Review Hook/Gate와 소비자용 Continuous Eval
- MIT License, Node.js 18+, runtime dependency 없음

## Verified

- 결정론적 Node test와 OwnHands 내부 Static Eval
- npm package allowlist
- local tarball 기반 clean Git fixture의 `init → doctor → eval --static-only`
- 공개 GitHub Release는 registry의 `ownhands@0.0.1` 조회와 fresh registry fixture 검증 뒤에만 생성

## UNOBSERVED

- 소비자 환경에서 Codex가 repository Hook을 신뢰·reload해 실제 실행한 결과
- 공개 설치본의 Runtime Eval 3개 항목
- 첫 실제 Feedback → Issue → Improvement → Evaluation → Adoption 순환

## Known limitations

- update, migrate, uninstall 명령 없음
- 자동 publish CI, 자동 merge·deploy 없음
- `eval --static-only`는 모델 동작을 증명하지 않음
- OwnHands Eval은 사용 프로젝트의 test·lint·build를 대신하지 않음
